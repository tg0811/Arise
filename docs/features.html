Side-by-side: where the two apps overlap

Both apps solve some of the same problems in different ways. For each row we'll pick one approach or blend them.

ConceptLevelUpTHE-SYSTEM
Unit of workOne-off Quests (expire in ~24h), mostly AI-generatedRecurring Disciplines (daily habits) you define once
DifficultyEasy / Medium / Hard as a label. XP is set per quest (by you or the AI)EASY / NORMAL / HARD / LEGENDARY, each with default gain/loss: 10/5, 25/15, 50/30, 100/0
FailingMissed deadline: quest removed, lose 25% of its XP (can drop you a level)Tap Fail or leave it undone: lose the discipline's XP. XP never goes below 0, and you never lose a level
StreakOne global daily streak, +1% XP per day with no capPer-discipline streak multipliers: 7d ×1.5, 14d ×2, 30d ×3, 90d ×4
Level curve130 XP for level 2, then each level costs ×1.5 more (gets steep fast)Fixed table to Lv 30: 300, 700, 1200 … 87,500 total
RanksE (1), D (6), C (11), B (21), A (31), S (41), with titles like "C-Rank Focused Engineer"E 1–5, D 6–10, C 11–15, B 16–20, A 21–25, S 26+. Titles: Awakened → Tested → Disciplined → Forged → Sovereign → Transcendent
Categories8 Realms (Mind, Body, Creation, Spirit, Creativity, Finance, Social, Meta); 4 shown in the header4 Attributes (Willpower, Strength, Vitality, Knowledge), calculated from your logs
RewardsCredits + Gems currency, store, buffs, daily lootbox, stakingNo currency. Mandates (loot chests) on level-up give cosmetics
Focus modeTimer quest: XP from estimated minutes, bonus for finishing earlyShield: 15/25/45 min, fails if you leave the app
Long horizonMajor Goals with deadlines (exams, projects, events)A fixed 180-day journey, a 24-node map and a Final Judgement
StorageBrowser localStorage, single deviceOn-device SQLite, single device
